## ПР1. Ответы на контрольные вопросы

**1. Чем компилируемый язык (C#) отличается от интерпретируемого (Python) с точки зрения того когда обнаруживаются ошибки?**

в C# код сначала компилируется и многие ошибки вылезают ещё до запуска, программа просто не соберётся пока их не исправишь. А в Python ошибка может найтись только когда интерпретатор дойдёт до нужной строки, то есть уже во время работы

**2. Что делает команда dotnet run на самом деле — из каких двух шагов она состоит?**

два шага. Сначала сборка (build), когда код превращается в .dll, а потом запуск того что получилось

**3. Зачем нужны папки bin/ и obj/ и почему их не нужно хранить в Git?**

В bin лежит собранная программа, а в obj промежуточные файлы для компилятора. Их не надо хранить в Git потому что они создаются автоматически при каждой сборке и их всегда можно получить заново из кода. Поэтому их добавляют в .gitignore

**4. В чём разница между git commit и git push?**

Commit сохраняет изменения в историю только локально у меня на компьютере. А push отправляет эти коммиты на GitHub, пока не сделаешь push там ничего не появится

**5. Чем отличаются конкатенация строк через + и интерполяция через $"..."? Какой способ предпочтительнее и почему?**

При конкатенации строки склеиваются плюсами, а при интерполяции переменные вписываются прямо в текст в фигурных скобках. Я считаю интерполяция лучше потому что так код читается проще и не надо следить за кавычками и плюсами

**6. Что произойдёт если разделить int на int если результат должен быть дробным? Как это исправить?**

Дробная часть просто отбросится, например 25 / 4 даст 6 а не 6.25. Чтобы исправить надо привести одно из чисел к double, например (double)25 / 4

**7. Чем const отличается от обычной переменной? Приведите свой пример когда стоит использовать const.**

Значение const задаётся один раз и потом его нельзя поменять, а обычную переменную можно менять сколько угодно. Использовать стоит когда значение точно не должно меняться, например у меня const double scholarshipGrade = 4.2, то есть проходной балл для стипендии

**8. Что такое top-level statements и чем они отличаются от классического class Program { static void Main() }?**

Это когда код пишется прямо в Program.cs без class Program и без метода Main, компилятор всё достраивает сам. Так кода меньше и для учебных задач это удобнее
